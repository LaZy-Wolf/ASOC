## Reading this

- **recall@5 0.864 -> 0.907** (+0.043) from the dense baseline to hybrid + rerank.
- **MRR 0.735 -> 0.773** (+0.037). MRR moves more than recall because reranking mostly reorders chunks that hybrid retrieval had already found, rather than finding new ones.
- **refusal recall** is the share of unanswerable questions correctly declined. Only the reranked config has a calibrated score to threshold on, so the others report n/a rather than a number derived from an arbitrary cutoff.
- **false refusal** is the share of answerable questions wrongly declined. It is the cost side of the refusal threshold and must be read alongside it.
- Latency is wall clock per query on CPU, including query embedding.

Gold labels are (document, heading substring) pairs, so re-chunking does not silently invalidate the set.
